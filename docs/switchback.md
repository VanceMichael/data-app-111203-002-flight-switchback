# switchback 实验分析方法说明

供调参评审使用。所有分析参数在评审前由设计文件显式给定，分析过程不从
观测结果中反推任何参数。演示数据为本地合成，不包含真实飞控参数。

## 1. 显式输入

`python3 -m analysis_app switchback --design design/switchback_design.json`

设计文件字段：

| 字段 | 含义 |
| --- | --- |
| `modes` | 两个模式名，第一个为基线模式（fixed），第二个为对比模式（adaptive），差值方向固定为 adaptive − fixed |
| `allocations` | 每个航次每个区块的预先确定 `planned_mode`；数据中的同名字段只用于逐分钟校验，分析以设计文件为准 |
| `washout_minutes` | 主分析洗脱分钟数 |
| `washout_grid` | 敏感性扫描的洗脱窗口集合（自动并入主分析窗口） |
| `cutoff_minute` | 分析截止分钟，`minute >= cutoff_minute` 的分钟不进入处理对比 |
| `min_valid_blocks` | 每个模式要求的最小有效区块数，达不到即降级 |
| `enumeration_flight_cap` | 合格航次数不超过该值时枚举全部 2^K 种再随机化 |
| `monte_carlo_replications` / `random_seed` | 超出枚举上限时的有种子抽样次数与种子，结果中披露 |
| `wind_imbalance_limit` / `deviation_rate_limit` / `alpha` | 风况失衡、执行偏离的降级阈值与检验水平 |

## 2. 分钟处置规则及原因

1. **意向处理（ITT）**：所有对比按设计的 `planned_mode` 聚合；实际 `mode`
   只用于计算执行偏离诊断，绝不重分组，避免按实际执行事后挑选处理组。
2. **停机保留**：`available=0` 的分钟只要落在 retained 区间，就照常计入该
   计划模式的暴露分钟，energy 按零聚合。不允许剔除低产分钟，否则低产分布
   在两模式间不对称时会人为制造电量差。
3. **洗脱段**：除航次首区块外，每个区块切换后的前 `washout_minutes` 分钟
   （含切换当分钟，`0 <= minute - switch_minute < W`）标记为 washout，
   不进入处理对比，但仍计入计划暴露与电量去向核算。原因：切换后数分钟存在
   残留效应，这些分钟的产出混合了前后两种模式。洗脱掩码只依赖设计切换点，
   对模式取补不变，因此全部再随机化共用同一掩码，随机化检验不会改动掩码。
4. **跨截止区块**：按分钟截断而不是整块丢弃——`minute >= cutoff_minute`
   的分钟标记 `after_cutoff`，截止前分钟照常参与；整块都在截止点之后的区块
   标记 `excluded_cutoff`。按分钟截断对称作用于两种模式，且不浪费截止点前
   的计划暴露；整块丢弃会在交替设计中系统性削弱其中一个模式。
5. **缺失区块**：设计覆盖但数据无任何分钟的区块标记 `missing`，不进入对比，
   在 `block_status_counts` 与暴露审计中披露；航次因此只剩单一模式 retained
   分钟时，该航次不进入随机化对比并记录原因。
6. **全量审计**：`exposure_audit` 保证 retained / washout / after_cutoff
   三类分钟数之和等于输入分钟数，三类电量之和等于输入总电量，没有分钟被
   静默丢弃。

## 3. 估计量与随机化检验

- 估计量：每个合格航次分别计算两模式 retained 分钟（含停机分钟）的分钟
  均值电量，做差（adaptive − fixed），再对合格航次等权平均，单位千瓦时/分钟。
  采用分钟均值而非区块均值，是因为相邻两个方向相反的切换，其残留偏差在
  区块均值口径下会恰好抵消而不可检测。
- 再随机化空间：每个航次保持区块结构、切换点与洗脱掩码不变，整体取计划
  序列或其取补序列，共 2^K 种航次级组合。**分钟从不被打散**，同一航次内
  区块符号联动，航次内风况相关结构在所有再随机化中保持不变。
- 航次差值在取补下整体变号，零分布即对固定差值向量做航次级符号翻转。
  K ≤ 枚举上限时精确枚举（无校正）；否则用固定种子的蒙特卡洛，符号向量
  成对取反以保证零分布严格对称，p 值做 plus-one 校正，重复次数与种子在
  结果的 `replications`、`random_seed` 中披露。
- 置信区间：平移零假设下零分布不变，区间为观测效应 ± 零分布双侧 alpha
  分位数；再随机化空间的最小可达尾概率仍大于 alpha 时区间标记不可界定。
- 报告同时给出与电量核算同口径的模式级累计（总电量、计划暴露分钟、
  可用分钟、有效区块数、有效分配航次数）及一个仅供核对的混合分钟率差值；
  检验结论始终以航次级随机化检验为准。

## 4. 降级为仅描述的条件

诊断出现任一标记，`interpretation` 降为 `descriptive_only`：

- `min_valid_blocks_unmet`：任一模式有效区块数低于设计门槛；
- `wind_imbalance`：两模式 retained 分钟的平均风速差超过阈值，并附航次级
  风差值的同结构随机化 p 值；
- `execution_deviation`：retained 分钟中实际 mode 偏离 planned_mode 的
  比例超过阈值（按模式分列偏离分钟数）；
- `few_eligible_flights`：合格航次少于 2，符号翻转空间不足；
- `flights_excluded_from_contrast`：有航次因单一模式无 retained 分钟被排除。

## 5. 洗脱敏感性

`washout_sensitivity` 对 `washout_grid` 中每个窗口用完全相同的其余配置
重跑分析，报告各窗口的效应、p 值、区间、合格航次、保留分钟与降级标记；
`sign_reversal` 标识效应方向是否在窗口间反转。评审据此判断结论是否依赖
洗脱窗口选择。

## 6. 可重放性与合成验证

- 设计文件、种子、抽样次数固定，同配置两次运行输出逐字节一致（测试覆盖）。
- `python3 -m analysis_app demo` 在单屏内完成五组合成航次验证：
  零效应（不显著且区间含零）、明显残留（效应随洗脱窗口加单调回升至真值）、
  缺失区块（标记 missing 且审计守恒）、不同航次长度（含停机分钟）、
  明显处理效应（显著且区间不含零）。
- 隔离模式入口 `scripts/run_analysis.py` 支持 `python3 -I` 运行，数据目录
  与脚本目录分离，路径以参数传入。
